# 00 - Overview

TaskFlow Pro - 팀 업무 관리 풀스택 웹 앱.

## 6개 파일 매핑

| 파일명 | 역할 | 알 수 있는 것 |
|---|---|---|
| `00-overview.md` | 길잡이 | 문서 구성과 읽는 순서 |
| `01-product.md` | WHY | 목표, 페르소나, 범위 |
| `02-specs.md` | WHAT | 데이터 모델, API, 화면 |
| `03-design.md` | HOW | 기술 선택과 트레이드오프 |
| `04-tasks.md` | 순서 | Phase 별 단계와 검증 |
| `05-conventions.md` | 규약 | 명명, 금지, 테스트, 커밋 |

## 읽는 순서

`00` > `01` > `02` > `03` > `04` > `05`

## 왜 이렇게 나누는가

관심사를 분리한다. 한 파일은 한 가지만 답한다.

- 왜 만드는지가 바뀌면 `01` 만 고친다.
- 무엇을 만드는지가 바뀌면 `02` 만 고친다.
- 어떻게 만드는지가 바뀌면 `03` 만 고친다.

의존은 위에서 아래로만 흐른다. 상위 결정이 하위의 입력이 된다.
규약 때문에 제품 방향이 바뀌는 일은 없어야 한다.
