# 01 - Product (WHY)

## 목표

팀 업무를 눈에 보이게 만든다. "지금 누가 뭐 해?" 라는 질문이 사라지게 한다.

## 페르소나

10명 규모 스타트업의 팀리더. 30대에서 40대.

## MVP 범위

| 항목 | 내용 |
|---|---|
| CRUD 4종 | 추가, 목록, 수정, 삭제를 모두 화면에서 한다 |
| 상태 분류 | `todo`, `in_progress`, `done` |
| 마감 시각 | `due_at` 을 날짜와 시간까지 지정하고 표시한다 |
| 테마 토글 | 라이트와 다크를 `localStorage` 에 기억한다 |
| 반응형 | 360px 에서도 화면이 깨지지 않는다 |

마감 시각은 날짜만으로 부족하다. `2026-12-31 18:00` 처럼 시간까지 적는다.

## UI 톤

Mac OS 스타일로 간다. 둥근 모서리, 부드러운 그림자, 반투명 카드,
시스템 폰트를 쓴다.

## 확장 (MVP 이후)

JWT 로그인, 팀 기능, Kanban 보드, 채팅, CI/CD 자동 배포.

## 범위 외 (지금은 만들지 않는다)

외부 결제, 네이티브 앱, WebRTC, 외부 캘린더 연동, 파일 업로드.

WebSocket 도 넣지 않는다. MVP 는 폴링으로 간다. 확장 단계에서 다시 본다.

## 성공 기준

실습에서 눈으로 확인 가능한 것만 적는다.

| 번호 | 기준 |
|---|---|
| S1 | 새로고침해도 데이터가 남는다 |
| S2 | 360px 에서 화면이 깨지지 않는다 |
| S3 | CRUD 4종이 화면에서 동작한다 |
| S4 | 테마 토글이 동작한다 |
