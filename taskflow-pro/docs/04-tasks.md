# 04 - Tasks (구현 순서)

## Phase 구성

| Phase | 이름 | 내용 | 단계 수 |
|---|---|---|---|
| 1 | 설계 | `CLAUDE.md` + `docs/` 6종 작성 | 10 |
| 2 | 백엔드 | `backend/` FastAPI, CRUD API 5개, Swagger 확인 | 10 |
| 3 | 프론트 | `frontend/` 화면, API 연결, git push | 8 |

Phase 이름과 개수는 위 3개로 고정한다. 바꾸지 않는다.

이후 "backend 진행해" 는 Phase 2 전체를 뜻한다.
"frontend 진행해" 는 Phase 3 전체를 뜻한다.

## 진행 규칙

1. 순서대로만 진행한다.
2. 병렬 진행을 금지한다.
3. 단계마다 검증을 거친다.
4. 검증에 실패하면 멈추고 보고한다.
